# 校园跑助手 (Campus Run Helper)

基于 MuMu 模拟器官方定位接口的自动跑步模拟工具，带本地地图定位插件。

## 功能

- **自动跑步**：读取路线文件，按设定速度沿操场路线循环移动模拟定位，并自动摇步模拟步频
- **速度机制**：每步坐标移动距离 = 设定速度 × 实测耗时，配速恒定，不受命令执行速度影响
- **地图定位插件**：本地地图服务 + 高德卫星底图，支持点击地图点选位置、输入坐标、回到起点，实时显示当前定位

## 文件说明

| 文件 | 说明 |
|---|---|
| `auto_run_gui.py` | 主程序（GUI），准备起点 / 开始跑 / 停止 / 速度调节 / 地图 |
| `map_server.py` | 地图插件服务端（本地 HTTP，端口 8765） |
| `map_page.html` | 地图页面（高德卫星底图 + 路线显示 + 点选定位） |
| `expand_route.py` | 路线加密 |
| `smooth_route.py` | 路线平滑 |
| `test_map_plugin.py` | 地图插件自动化测试 |
| `test_speed_loop.py` | 配速恒定验证测试 |

## 使用前提

- Windows + MuMu 模拟器（`mumu-cli.exe` 位于 MuMu 安装目录）
- Python 3
- 路线文件 `route.txt`（高德坐标，格式：`经度,纬度`，每行一个点）
