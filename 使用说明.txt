========================================
  校园跑自动刷跑工具 - 使用说明
========================================

【原理】
不需要Root，不需要装任何手机APP。
电脑通过无线调试给手机发"假定位"，
跑步APP以为你在操场上跑，实际上你在床上躺着。
按一下回车就开始，按Ctrl+C就停。

========================================
第一步：手机上的操作（只需要做一次）
========================================

1. 打开手机「设置」
2. 拉到最下面，点「关于手机」
3. 找到「版本号」，连续快速点7次
   （会提示"已进入开发者模式"）
4. 回到设置主页面，找到「系统和更新」/「更多设置」
5. 点「开发人员选项」
6. 打开这两个开关：
   - USB调试
   - 无线调试
7. 点进「无线调试」，选「使用配对码配对设备」
8. 屏幕上会显示：
   - 一个6位配对码
   - 一个IP地址和端口号（比如 192.168.1.5:37123）

========================================
第二步：电脑上连接手机
========================================

1. 确保手机和电脑连同一个WiFi
2. 在E:\跑步文件夹里，地址栏输入 cmd 回车，打开命令行
3. 输入下面这条命令（把括号里的换成你手机上显示的IP和端口）：

   platform-tools\adb.exe pair 192.168.1.5:37123

4. 提示输入配对码时，输入手机上显示的6位数字，回车
5. 提示"配对成功"后，再输入下面这条命令（这次用无线调试主页面的IP和端口，不是配对页面的）：

   platform-tools\adb.exe connect 192.168.1.5:41234

6. 提示"已连接"就成功了

========================================
第三步：设置你的跑步路线
========================================

1. 用记事本打开 E:\跑步\route.txt
2. 删掉里面的示例数据
3. 打开浏览器，访问这个网站：
   https://uri.amap.com/marker
4. 搜索你的学校操场
5. 右键点击地图上的位置，会弹出经纬度数字
6. 沿着操场跑道，按你平时跑步的方向，
   每隔20-30米右键取一个点
7. 把每个点的"纬度,经度"按顺序复制到route.txt里
   每行一个，一圈大概取15-20个点就够了

========================================
第四步：开始跑
========================================

1. 打开运动世界校园APP，准备开始跑步
2. 回到电脑，在E:\跑步文件夹地址栏输入 cmd 回车
3. 输入：

   python auto_run.py

4. 看到"模拟定位已开启"后，马上切回手机点开始跑步
5. 等着就行，它会自动沿着跑道一圈一圈跑
6. 跑够圈数后，回到电脑按 Ctrl+C 停止

========================================
可调参数
========================================

用记事本打开 auto_run.py，最上面这几行可以改：

SPEED = 2.8    ← 跑步速度，数字越大跑越快
                普通慢跑2.5-3.5之间，别太快也别太慢

LOOP = True    ← True就是自动无限循环，想跑几圈跑几圈

UPDATE_INTERVAL = 1  ← 每隔几秒更新一次位置，默认1秒

========================================
注意事项
========================================

1. 跑完之后一定要按Ctrl+C停止，会自动关闭模拟定位
   不然手机会一直定在操场位置不动
2. 速度别调太快，超过6m/s（21km/h）会被检测出来
3. 第一次用建议先试跑一圈看看正不正常
4. 每次用之前都要重新连一次无线调试
   （手机重启或者关了无线调试就要重新pair+connect）
5. 如果连接断了，重新执行第二步的connect命令就行

========================================
常见问题
========================================

Q: 提示"没有检测到设备"？
A: 先执行 platform-tools\adb.exe devices 看看有没有设备
   没有的话就是无线调试没连好，重新connect

Q: 跑步APP里显示的位置不动？
A: 确认是先开auto_run.py再点开始跑步，顺序别反了

Q: 会被封号吗？
A: 这个方法比装虚拟定位APP隐蔽很多，
   因为是系统级模拟，不修改任何APP数据。
   但还是那句话，别跑太夸张，正常速度就没事。
